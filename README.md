# 🌐 Networks-Chat-Application

A UDP-based Python chat client using a custom protocol and wireguard encryption.

## 📦 Requirements

* Python 3.11.9
* `cryptography`
* `prompt_toolkit`
* `msgpack`

Install dependencies:

```bash
pip install cryptography prompt_toolkit msgpack
```

## 🚀 Running the Client

```bash
python cli.py
```

Follow the CLI commands to connect to the server, join channels, send messages, and manage your session.
